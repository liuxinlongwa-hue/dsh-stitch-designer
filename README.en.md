# dsh-stitch-designer

**Google Stitch AI design plugin for DeepSeek Harness (DSH) — text-to-UI generation, in-session live preview, iterative editing, 1:1 HTML export**

Design interfaces inside [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH) with [Google Stitch](https://stitch.withgoogle.com): type a requirement → auto-generate high-fidelity UI designs → preview live in the session panel → iterate via conversation → export a 1:1 runnable page (packable as EXE).

## 📦 Install (Human)

```bash
# 1. Clone
git clone https://github.com/liuxinlongwa-hue/dsh-stitch-designer.git
cd dsh-stitch-designer

# 2. One-command install (copies plugin + writes DSH composition)
bash install.sh

# 3. Get a free Stitch API key (400 daily credits)
#    a. Open https://stitch.withgoogle.com and sign in
#    b. Avatar → Stitch Settings → API key → Create key
#    c. Save the full key (starts with AQ.):
#       echo 'AQ.your-key' > ~/.stitch/key && chmod 600 ~/.stitch/key

# 4. Restart DSH (dsh web). The "AI Design" button appears in the session header.
```

## 🤖 Install (AI / Agent)

Hand this repository link to your AI (Claude / DeepSeek / Codex...). After reading this file it can configure everything:

1. **Install the plugin**: copy `plugin.js` / `client.js` / `package.json` into the DSH profile node_modules:
   `${DSH_HOME:-$HOME/.dsh}/profiles/web/node_modules/stitch-designer/`
2. **Symlink**: in the npx-cache node_modules (DSH's real install location, e.g. `~/.npm/_npx/<hash>/node_modules/`):
   `ln -sfn <above-dir> <npx-cache>/stitch-designer`
   (DSH loader resolves `import('stitch-designer')` from its own location; client-modules resolves via `createRequire(profileDir)` — both must hit.)
3. **Composition**: append to `cordis.patch.yml`:
   ```yaml
   - insert:
       - id: stitch-designer
         name: 'stitch-designer'
   ```
4. **API key**: walk the user through https://stitch.withgoogle.com → Stitch Settings → API key → Create key (free, `AQ.`-prefixed). Save to `~/.stitch/key` (chmod 600).
5. **Restart DSH**, verify the "AI Design" button appears.
6. **Usage**: user requests a design → `POST /stitch/api/generate` (`{prompt, deviceType}`) → generation takes ~1-2 min (async; poll `list_screens`) → panel shows `/stitch/screens/{id}.png` hi-res preview → user gives feedback → `POST /stitch/api/edit` (`{screenName, prompt}`) → when approved, `POST /stitch/api/html/{screenId}` exports 1:1 HTML.

## 🔌 Plugin API (Host Routes)

| Method | Path | Description |
|---|---|---|
| GET | `/stitch/api/state` | Project + screen list (hi-res preview URLs, auto-downloaded) |
| POST | `/stitch/api/generate` | `{prompt, deviceType}` generate a design |
| POST | `/stitch/api/edit` | `{screenName, prompt}` edit a screen |
| GET | `/stitch/api/html/{screenId}` | Export 1:1 HTML |
| GET | `/stitch/screens/{id}.png` | Hi-res preview (local cache) |
| GET | `/stitch/html/{id}.html` | HTML artifact |

> Hi-res: Stitch's `screenshot.downloadUrl` is a thumbnail; the plugin appends **`=s0`** for the original resolution.
> Default project: `5188527734101747624` (change `DEFAULT_PROJECT` in `plugin.js`).

## 🛠 How It Works

- **Host** (`plugin.js`, Node): calls the official Stitch MCP HTTP API (`stitch.googleapis.com/mcp` + `X-Goog-Api-Key`) directly — generate/edit/list/cache/export. No DSH mcp-client dependency.
- **Client** (`client.js`, browser bundle): `__ModuleLoader__.load` format, registers the "AI Design" panel in the session header Slot.
- No build chain; edits take effect after a DSH restart.

## 🔒 Security

- API key lives in `~/.stitch/key` (chmod 600) — never hardcoded, never committed.
- Do not commit keys to any public repository.
